# RatTADStask

**Play it in your browser: https://lustigb.github.io/rattadstask/**

A 3D model of the TADS rodent navigation task. You play the rat: run in the wheel to open the
doors, choose an arm, break the laser at the far end to commit, and lick the water if you chose
right. The rewarded order is Left → Centre → Right → Centre …, and it only moves on after a
correct choice.

Click the game once to start (browsers need a click before sound and mouse control).
Press **H** in the game for the controls, a room-light slider and sound on/off.

| Keys | |
|---|---|
| WASD / arrows | move |
| Mouse or Q / E | turn / look |
| Shift | run |
| Space | jump / hop in or out of the wheel |
| Click or F | lick |
| C | change the main view |
| 8 / 9 | follow-cam / overhead panels |
| Esc | free the mouse |

Built with Godot 4 (web export). This repository only holds the exported web build.
